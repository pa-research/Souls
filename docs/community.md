# Community simulation: 1000 personas, 280 days

`dotnet run --project tools/Souls.Sim -c Release -- --community 280 --personas 1000 --out docs/community.md`: the server's community code (Souls.Server's AiCommunity) on a simulated clock, every game a real one between the bots. Ticks of 30 s, 2 games an hour per online persona, 3 live games, at least 16 online. Seasons of 56 days.
