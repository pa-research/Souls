# Discord Activity artwork

The art of the Souls Discord application (Developer Portal), made from the heroes' portraits
(`Content/Images/Player/Portraits`) and the logo (`Content/Images/logo.png`):

- `icon.jpg` (1024×1024): the app icon, the Lightbringer with the logo.
- `cover.jpg` (1024×576): Activity cover art on the Activity Shelf, the four heroes with the logo.
- `background.jpg` (1024×576): Activity background in grid view, the heroes at the edges and a dark centre.
